# 科学 / STEM 视频频道清单｜9–15 岁

> **整理日期**：2026-08  
> **适用**：9–15 岁，英语母语或高阶英语学习者  
> **孩子已知兴趣**：医学与人体（已读完 Adam Kay 儿童线）  
> **说明**：以下均为长期活跃、口碑良好的频道（主要为 YouTube）。**订阅数与播放量随时变化，本文只作量级描述，不给精确数字**；同一频道内单集难度与主题差异较大，**建议家长先预览**。

**教育价值评级**：⭐ 越多表示知识密度与思维训练价值越高，与「好看程度」无关。

## 二、分类详表

### 2.1 动手实验 · 工程（最容易点燃兴趣）

| 频道 | 典型内容 | 为什么值得看 |
| --- | --- | --- |
| **Mark Rober** | 松鼠障碍赛迷宫、玻璃钢琴、防偷快递「屁味炸弹」 | 把工程做成娱乐大片，激发「我也想造一个」的冲动 |
| **CrunchLabs** | 配合每月订阅盒子的搭建教学 | 看 + 做结合，是全清单里唯一真正落到动手的 |
| **The Action Lab** | 真空、强磁、非牛顿流体等极端条件实验 | 用反直觉现象建立物理直觉 |
| **Steve Mould** | 「链条喷泉」等经典自发现象 | 讲解最清晰的一档，趣味与严谨兼顾 |
| **Science Max** | 把课堂小实验放大成巨型版本 | 专为儿童设计，安全边界清楚 |
| **The Slow Mo Guys** | 超高速摄影拍爆炸、水滴、气球破裂 | 慢镜头揭示肉眼看不见的过程 |
| **Physics Girl** | 物理实验与现象讲解 | 优秀女性科学榜样（注意更新已停滞） |

### 2.2 动画讲解 · 宏大概念（深度思考型）

| 频道 | 典型内容 | 为什么值得看 |
| --- | --- | --- |
| **Kurzgesagt** | 宇宙尺度、免疫系统、文明未来、伦理思辨 | 视觉艺术级动画，把「大问题」讲得让人愿意想下去 |
| **MinutePhysics** | 相对论、光速、守恒定律 | 几分钟讲透一个概念，适合当概念补丁 |
| **TED-Ed** | 科学、历史、逻辑各科动画短课 | 题材最广，官网配套课后问题，可当微课用 |
| **SciShow** | 各类科学话题快讲，紧跟新闻 | 更新频繁，适合日常泛看；Kids 版给低龄 |
| **Veritasium** | 挑战直觉的物理与工程探究 | 教的不是结论，是「如何科学地质疑」 |

### 2.3 人体 · 医学 · 生物（与孩子兴趣直接契合）

| 频道 | 典型内容 | 适龄与注意 |
| --- | --- | --- |
| **Operation Ouch!** | 双胞胎医生 Chris & Xand van Tulleken 讲人体、急诊、就医全过程 | 8–13；**与 Adam Kay 风格同源**（英式幽默 + 真实医学），是本类首选 |
| **Nucleus Medical Media** | 手术流程、疾病机制的医学级 3D 动画 | 12–15；专业度极高，部分手术动画较写实 |
| **Institute of Human Anatomy** | 用**真实捐赠遗体标本**讲解结构 | 13–15；**含真实人体组织画面，务必家长先预览并陪看** |

### 2.4 趣味思辨 · 数学 · 逻辑

| 频道 | 典型内容 | 为什么值得看 |
| --- | --- | --- |
| **xkcd's What If?** | 「用光速投出棒球会怎样」式的严肃推演 | 费米估算与数量级思维的最佳训练（以书为主） |
| **Numberphile** | 数学趣题、著名猜想、冷知识 | 让数学有故事、有人物，不只是习题 |
| **Vsauce** | 「零是什么颜色」类脑洞与哲学追问 | 培养好奇心与批判思维；部分内容较烧脑，低龄慎入 |

### 2.5 自然 · 地球

| 频道 | 典型内容 | 为什么值得看 |
| --- | --- | --- |
| **BBC Earth** | 顶级自然纪录片精选片段 | 世界级影像 + Attenborough 旁白，也是极好的听力材料 |
| **Deep Look** | 超微距拍摄昆虫、水生微生物 | 展示肉眼不可见的微观之美，每集短、画质极高 |
| **National Geographic Kids** | 动物与自然趣味短片 | 低龄友好、事实可靠 |

## 四、难度梯度

| 年龄段 | 主力频道 | 说明 |
| --- | --- | --- |
| 9–11 岁 | Operation Ouch!、Science Max、SciShow Kids、Nat Geo Kids | 语速较慢、概念具体、无需背景知识 |
| 12–15 岁 | Kurzgesagt、Veritasium、What If?、Vsauce、Institute of Human Anatomy、Numberphile | 需要一定抽象思维与词汇量；建议开英文字幕 |
| 全龄可看 | Mark Rober、BBC Earth、Deep Look、TED-Ed | 视觉驱动，语言门槛低，低龄也能有收获 |

## 五、视频 + 阅读联动计划

> 观看驱动兴趣，阅读补足系统性。以下配对与本库购书清单打通。

| 先看 | 再读 | 衔接逻辑 |
| --- | --- | --- |
| Operation Ouch! | **Kay's Anatomy**（已读） | 同为英式医学幽默；影像建立直觉，书补系统 |
| Institute of Human Anatomy | **The Way We Work**（Macaulay） | 真实标本 → 手绘剖面，两种可视化互补 |
| Nucleus Medical Media（免疫相关） | **Immune**（Kurzgesagt 团队） | 同源视觉语言，书是频道内容的深潜版 |
| Kurzgesagt 免疫系列 | **Immune** | 作者即频道创始人 Philipp Dettmer |
| Kurzgesagt 进化／细胞主题 | **Explodapedia: Evolution / The Cell** | 动画建立框架，书补细节与史脉 |
| Veritasium、MinutePhysics | **Thing Explainer** → **What If? 2** | 从概念讲解走向自主推演 |
| Steve Mould | **The Bacteria Book**（Steve Mould, DK） | 同一作者，频道与书风格一致 |
| The Action Lab、Slow Mo Guys | **Horrible Science**（光／声／力／电分册） | 现象先震撼，书再讲原理 |
| BBC Earth、Deep Look | **Explodapedia: Rewild** | 自然影像 → 生态与再野化的行动视角 |
| Numberphile | **A Short History of Nearly Everything**（YR Ed.） | 从数学趣题延伸到科学史全景 |

**三频道起步组合**：Operation Ouch!（医学兴趣）+ Mark Rober（动手热情）+ Kurzgesagt（深度思考），覆盖面最广。

## 六、家长使用建议

| 事项 | 做法 |
| --- | --- |
| **内容筛选** | 使用 YouTube Kids，或普通版的「受监管账户」（Supervised Account）限制推荐范围 |
| **需预览的频道** | Institute of Human Anatomy（真实组织）、Vsauce（哲学向较烧脑）、Nucleus（写实手术动画） |
| **防无限刷** | 用播放列表代替首页推荐；约定单次时长，看完聊三分钟「学到了什么」 |
| **兼作英语输入** | 优先开**英文字幕**而非中文；BBC Earth、TED-Ed 语速适中，适合精听 |
| **看后延伸** | 按第五节配对表接书，把「看过」转成「读过」 |

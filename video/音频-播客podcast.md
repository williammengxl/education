## 一、关于"播放量"：为什么这份清单给的是排名而不是播放数

**Apple Podcasts 与 Spotify 均不公开单档节目的播放/下载数据**，这是行业惯例。第三方估算工具（CastFox、Rephonic、Podscan 等）给出的数字区间极宽且相互矛盾——例如同一页面把 Brains On! 估为"月触达 750 万–2200 万"，却又标注"累计播放 1400 万"，逻辑上无法自洽，**不宜作为选择依据**。

因此本清单改用三类**可查证**的规模指标：

| 指标 | 说明 | 可靠性 |
| --- | --- | --- |
| **Apple 榜排名** | 2026-09 实测美国区分类榜实时位次 | 🟢 客观、可复现 |
| **Edison 排名** | Edison Podcast Metrics 2025 年度《美国 12 岁及以下儿童播客 Top 10》，行业公认的面板测量 | 🟢 权威第三方 |
| **出版方披露** | 公司公开发布的累计收听/下载数字 | 🟡 官方口径，未经审计 |

**已公开披露的规模数字**：
- **Tinkercast**（Wow in the World 出品方）：旗下节目累计 **3 亿次收听**，过去一年 **570 万小时**收听；官方称 Wow in the World 为"史上收听量最高的儿童与家庭播客"
- **Brains On!**：系列累计下载超 **1.3 亿次**
- **CrowdScience**：第三方估算月度独立听众约 **23 万–80 万**（BBC World Service 不单独披露分档数据）

# 五、家长提示

| 事项 | 做法 |
| --- | --- |
| **需按单集筛选** | **Ologies** 与 **Science Vs** 面向成人听众，含脏话或成人健康话题；建议先试听 |
| **低龄的干净替代** | 想听 Ologies 风格又要放心，直接订阅 **Smologies**（官方儿童安全版，无脏话、适合课堂） |
| **Sawbones 须先筛单集** | 主题最贴 Kay's Marvellous Medicine，但面向成人、Apple 归类 Comedy；建议从 *Medical Questions for Kids* 特辑入门 |
| **兼作英语听力** | 儿童向节目（Brains On!、But Why、Tumble）语速适中、发音清晰，适合泛听；CrowdScience 与 The Naked Scientists 为英式发音；StarTalk 与 Stuff You Should Know 语速快、俚语多，适合进阶 |
| **场景搭配** | 通勤与睡前用短节目（Six Minutes、Short Wave），周末整块时间听叙事型（CrowdScience、Terrestrials、Tumble、Forever Ago） |
| **区域限制** | BBC 系（CrowdScience、Naturebang、The Infinite Monkey Cage）部分内容在英国以外可能受限 |
| **优先从官方地址订阅** | 播客搬运与同名节目常见（例如搜 "Wow in the World" 会出现多个同名山寨源），从上表 Apple ID 进入可避免 |
| **注意节目状态** | Moment of Um 停在 2025-10、The Infinite Monkey Cage 处于季间休息，这两档按片库听即可，别等更新 |

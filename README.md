## 使用约定

- **文档语言**：中文为主，书名与专有名词保留英文原文
- **难度标注**：统一使用蓝思值（Lexile），标注来源并注明 ±40L 的正常误差
- **时效信息**：影视上线时间、新书出版计划、AI 产品功能与定价等注明更新日期，引用时请核对

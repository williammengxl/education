# 教育类 AI 工具 / APP 全景指南

> **整理日期**：2026-08
> **覆盖受众**：9–14 岁家庭自学与家长辅导；国际学校教师、双语教学、留学备考
> **说明**：产品功能、定价与地区可用性会变，请以各产品官网为准；付费仅标注「免费 / 部分免费 / 订阅」量级，不作实时报价。

---

## 选型原则

1. **引导思考优于直接给答案**：数学与写作尤其应优先选「显示步骤 / 追问式」的工具
2. **AI 是个性化学习脚手架**：在跨文化、多语言课堂中辅助沟通与理解，而非替代深度思考与原版阅读
3. **未成年人需家长管控**：关闭训练数据分享、限制代写作业、约定使用时长
4. **事实与数据需核对**：蓝思值、科学结论、销量、考纲信息等以权威来源为准
5. **先试用再订阅**：多数工具有免费基础版，进阶功能（Notion AI、Photomath Plus、Duolingo Max 等）按需付费

## 四、家庭短名单（本库场景优先试用）

面向本资料库：**英文原版阅读（科普 + 奇幻）+ 9–14 岁家庭学习**。

| 优先级 | 名称 | 建议用法 |
| :---: | --- | --- |
| 1 | ChatGPT 或 Claude | 讲解章节、出理解题、用简单词释难句；家长账号管控 |
| 2 | NotebookLM | 上传 `read-books` 中的书单与指南，问阅读路径与讨论题 |
| 3 | Speak 或 ChatGPT Voice | 每周固定口语：复述情节、回答开放问题 |
| 4 | Khanmigo | 数学与科学用追问式辅导，少用直接给答案的工具 |
| 5 | Perplexity | 查作者、适龄、奖项与背景知识，带回源核对 |
| 6 | Canva 或 Notion AI | 把书单与周计划做成家庭可读的表与卡片 |

## 五、合规与风险

| 事项 | 说明与建议做法 |
| --- | --- |
| 数据合规 | 机构选型需符合 GDPR、FERPA、COPPA 等地区隐私法规；MagicSchool、Khanmigo 等有相应合规认证 |
| 学术诚信 | Grammarly、Brisk 等具备 AI 代写检测，可用于维护国际课程的诚信要求 |
| 幻觉（编造事实） | 科学结论、数据、蓝思值交叉核对出版社或 Lexile 等权威源 |
| 代写依赖 | 约定「AI 只给思路与例题，最终作业自己完成」 |
| 隐私 | 少上传真实姓名、学校、成绩单；未成年人开启家长控制 |
| 替代阅读 | 主业仍是原版书与真实输入，AI 只做脚手架 |
| 搜题类 APP | 限时、家长陪同；优先选「显示步骤」而非「只给答案」 |
| 付费决策 | 多数工具有免费基础版，进阶功能建议先试用再订阅 |

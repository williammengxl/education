# 第一部分 · 认识这套书

## 一、为什么选这套书

| 教育维度 | 书中的具体体现 | 对孩子的实际意义 |
| :-- | :-- | :-- |
| **自我认同** | 主角 Percy 有 ADHD（注意力缺陷）和 dyslexia（阅读障碍），书中解释为"半神的战斗本能"和"大脑天生适配古希腊文" | 把"缺陷"重构为"天赋"，学习困难的孩子在这里第一次成为英雄 |
| **知识密度** | 每一册即一部希腊神话导览，覆盖 50+ 神祇与怪物 | 一次读完抵得上一本神话教科书，且不枯燥 |
| **叙事技巧** | 第一人称 + 幽默章节标题（如 *I Accidentally Vaporize My Pre-Algebra Teacher*） | 章节标题本身就是"预测式阅读"训练素材 |
| **语言难度** | 蓝思 590L–740L，句子短、对话多、俚语生活化 | 是"从桥梁书跨向长篇小说"最平滑的一级台阶 |
| **品格教育** | 忠诚（fatal flaw）、牺牲、宽恕、重组家庭、接纳"不体面"的亲人 | 讨论深度远超同龄冒险书 |
| **阅读续航** | 正传 5 册 + 衍生 25+ 册，同一世界观 | 一旦入坑，可支撑 2–3 年的自主阅读量 |
| **跨媒介支持** | Disney+ 剧集、有声书、图像小说、百老汇音乐剧齐备 | 读不动时有大量"扶手"，不容易半途而废 |

> **创作缘起**：Rick Riordan 最初是把这个故事编给自己患有 ADHD 和阅读障碍的儿子听的睡前故事。这套书从诞生第一天起，服务对象就是"读不进书的孩子"。

> **教育者提醒**：这套书最大的价值不在词汇量，而在于建立"我是一个会读英文长篇的人"这一自我认知。**第一册读完的心理收益 > 后面四册的总和。**

## 二、Riordanverse 全景地图

Rick Riordan 构建了一个共享宇宙，核心设定是**各文化的神话在现代世界真实存在**。各系列共享世界观，角色偶有交叉。

### 2.1 系列关系时间线

```
Percy Jackson & the Olympians (2005-2009) ← 一切的起点，必读
    │
    ├── The Heroes of Olympus (2010-2014) ......... 直接续集（希腊+罗马）
    │       │
    │       └── The Trials of Apollo (2016-2020) .. 进一步续集
    │
    ├── The Senior Year Adventures (2023-) ........ Percy 高三生活，轻松番外
    │
    ├── The Nico di Angelo Adventures (2023-) ..... Nico & Will 支线
    │
    ├── The Kane Chronicles (2010-2012) ........... 埃及神话，独立主角
    │
    ├── Magnus Chase (2015-2017) .................. 北欧神话，Annabeth 的表哥
    │
    └── Camp Half-Blood: The Wild Zone (2026-) .... 新一代，2026-09 上市
```

### 3.2 世界观核心设定

> **核心前提**：希腊诸神真实存在。随着西方文明中心的迁移，奥林匹斯山如今位于纽约帝国大厦上方（600 层）。诸神与凡人所生的后代称为**半神 / 混血种**（Demigod / Half-Blood），拥有超凡能力，但终身被怪物追杀。

| 设定 | 说明 |
| :-- | :-- |
| **混血营（Camp Half-Blood）** | 纽约长岛的半神训练营，酒神狄俄尼索斯任营长，半人马凯龙任训练总监 |
| **迷雾（The Mist）** | 魔法屏障，让凡人看不见超自然事物，会自动"合理化"所见 |
| **ADHD** | 半神的战斗本能，在凡人世界表现为注意力缺陷 |
| **阅读障碍** | 半神大脑天生适配古希腊文，所以读英语困难 |
| **神圣法则** | 诸神不能直接干预人类事务，必须借由子女行动 |
| **三巨头誓言** | 宙斯/波塞冬/哈迪斯曾立誓不再生育混血子女——Percy 的存在本身就是"违禁品" |
| **天青铜（Celestial Bronze）** | 唯一能伤到怪物的金属，对凡人无害 |

> ⚠️ **两个重要提醒**
> 1. **难度不是递增的**。第 1、2 册（740L）反而是全系列语言最难的，第 4 册（590L）最易。真正加重的是情节复杂度和情感重量，不是语言。所以"读完第 1 册就轻松了"是成立的。
> 2. **蓝思值各来源有出入**（±40L 属正常，因版本与测评批次不同），页数也随平装/精装版本变化。以上采用图书馆 MARC 编目与 AR 官方数据，作参考即可，精确值请查 [lexile.com](https://lexile.com)。

# 第三部分 · 怎么读

## 十一、读前自测：孩子现在能读吗？

| 能力指标 | 达标线 | 未达标的替代方案 |
| :-- | :-- | :-- |
| 蓝思值 | ≥ 600L | 先读 *Charlotte's Web*（680L）或 *Holes*（660L）过渡 |
| 单册厚度承受力 | 能读完 150 页以上的章节书 | 先用图像小说版建立故事骨架 |
| 生词容忍度 | 每页 ≤ 5 个生词仍能读下去 | 改为"亲子共读"或"有声书跟读"模式 |
| 神话背景 | 知道宙斯、波塞冬、冥界即可 | 看下方第十三章速查表，或听 *Greeking Out* 播客 |
| 持续注意力 | 单次 20 分钟不中断 | 拆成 10 分钟 × 2，或用有声书替代 30% 阅读量 |

**快速试读法**：让孩子读第 1 章前 3 页。**能笑出来 → 直接开读；读得皱眉 → 先上图像小说或有声书。**

## 十二、阅读顺序路线图

### 12.1 五条路线

| 路线 | 顺序 | 适合谁 |

| **E. 最精简（时间有限）** | The Lightning Thief → The Last Olympian → The Lost Hero → The Son of Neptune | 只想了解主线的读者。**不推荐给孩子**，跳读会损失大量情感铺垫 |

### 14.2 语言特色与应对策略

| 语言现象 | 举例 | 应对建议 |
| :-- | :-- | :-- |
| 大量美式俚语口语 | *"Bright side: ..."*、*"Give me a break."* | 不必逐句查，联系上下文猜即可 |
| 希腊语专有名词密集 | Anaklusmos, Ophiotaurus | **允许跳过发音**，认字形即可，千万别卡在这里 |
| 章节标题夸张搞笑 | *Grover Unexpectedly Loses His Pants* | 读前先看标题猜内容，是极佳的预测训练 |
| 第一人称吐槽式旁白 | Percy 直接对读者说话 | 适合朗读，语气夸张更有趣 |
| 短句 + 大量对话 | 平均句长很短 | 这是这套书好读的根本原因，不必担心 |
| 破折号 / 省略号打断句 | — 与 ... 频繁出现 | 提示情绪，读时可停顿夸张处理 |

## 二十、常见问题 FAQ

| 问题 | 解答 |
| :-- | :-- |
| **适合多大的孩子？** | 最佳入门 8–10 岁（三到五年级），核心读者群 9–14 岁。成人也能享受，幽默和情节同样有吸引力。 |
| **需要先了解希腊神话吗？** | **不需要。** Riordan 在故事中自然地解释了所有神话背景。实际上很多孩子是**通过** Percy Jackson 学会希腊神话的。第十三章的速查表看一遍就够了。 |
| **阅读顺序必须严格遵守吗？** | 正传 5 册必须按顺序；HoO 必须在正传之后；ToA 必须在 HoO 之后；Kane Chronicles 可完全独立阅读。详见 12.3。 |
| **男孩女孩都适合吗？** | **都适合。** 虽然 Percy 是男孩，但 Annabeth、Thalia、Clarisse 等女性角色同样强大丰满。HoO 有大量女性视角，Kane Chronicles 的 Sadie 是女性叙述者之一。 |
| **孩子说"生词太多读不下去"？** | 用"五指法则"测：随机一页，读不懂的词超过 5 个才算太难。多数情况是**情节还没进入**——坚持到第 6 章（夺旗赛）通常就上瘾了。 |
| **该不该查生词？** | 第一遍**不查**。只圈出反复出现且影响理解的词，一章最多 3 个。生词本超过 10 个/周就是过量，会杀死阅读乐趣。 |
| **可以先看剧再读书吗？** | 不建议，剧集会替代想象力建构。**唯一例外**：孩子完全读不进去时，用 S1 前两集"钓"他入坑。 |
| **中文版能替代英文版吗？** | 中文版由接力出版社等引进，翻译整体可以。但 Percy 的第一人称幽默和双关语在翻译中损失很大。折中方案：中文读第 1 册建立骨架，英文从第 2 册开始。 |
| **内容会不会太黑暗/暴力？** | 有战斗和角色死亡（第 3、5 册尤甚），但无血腥描写。9 岁以下建议共读。涉及"神明生育大量私生子"的设定，需要简单解释。 |
| **一定要读完 5 册吗？** | **不必。** 第 1 册读完就已达成主要教育目标。允许中途换书，比强迫读完更重要。 |
| **读完正传后孩子不想读 HoO？** | 很正常，因为厚度翻倍。可先给 *Percy Jackson's Greek Gods*（轻松）或换 Kane Chronicles 缓冲。 |
| **有配套词汇学习资源吗？** | [vocabulary.com](https://www.vocabulary.com) 有 Percy Jackson 各册的专属词表，搜索书名即可。 |

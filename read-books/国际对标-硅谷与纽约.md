### 1.2 四把标尺

## 二、官方基准数据（CCSS + NWEA）

### 2.1 各年级蓝思带与 RIT 带（CCSS "Stretch" 标准）

这是 Common Core 反推自"大学与职业准备度"（College & Career Readiness）的官方标准：

| 学段 | 旧蓝思带 | **CCSS Stretch 蓝思带** | 对应 MAP RIT 带 |
| :-- | :-: | :-: | :-: |
| Grade 2–3 | 450–725L | **420–820L** | 190–212 |
| Grade 4–5 | 645–845L | **740–1010L** | 208–223 |
| **Grade 6–8** | 860–1010L | **925–1185L** | **218–232** |
| Grade 9–10 | 960–1115L | **1050–1335L** | 225–241 |
| Grade 11–CCR | 1070–1220L | **1185–1385L** | 232–244 |

> 📌 **划重点**：Grade 6–8 的目标上限是 **1185L**。很多中国家庭把"读完哈利·波特（约 880–1030L）"当作终点，但按 CCSS 标准，那只是 Grade 6–8 区间的**下半段**。

### 2.2 MAP 阅读 RIT 百分位表（Grade 5–8，2025 全美常模·秋季）

| 百分位 | Grade 5 | Grade 6 | Grade 7 | Grade 8 | 含义 |
| :-: | :-: | :-: | :-: | :-: | :-- |
| 50th | 204 | 209 | 212 | 216 | 全美平均 |
| 75th | 215 | 220 | 223 | 227 | 良好 |
| 80th | 218 | 223 | 226 | 230 | **强区中位数大致在此** |
| 85th | 222 | 227 | 230 | 234 | 强区中上 |
| 90th | 226 | 231 | 234 | 238 | **对标硅谷/纽约优质校的合理目标** |

## 三、硅谷 vs 纽约：两种教育生态

对标"美国"是个模糊说法。硅谷和纽约的英文能力要求**方向不同**，同时对标意味着要建两条能力线。

### 3.1 生态对比

| 维度 | 硅谷（湾区） | 纽约 |
| :-- | :-- | :-- |
| **主力学校类型** | 公立强学区为主（PAUSD、Cupertino、Fremont、Los Altos） | 公私立并重；私立名校与选拔性公立并存 |
| **学术重心** | STEM 导向，数学与科学竞赛文化浓 | 人文导向，写作、历史、艺术分量重 |
| **英文能力偏好** | **科技类非虚构阅读 + 技术性写作** | **文学分析 + 论证写作 + 口头表达** |
| **课堂形式** | 项目制（PBL）、小组协作 | 研讨式（Harkness / Socratic Seminar），围桌辩论 |
| **代表性选拔** | 学区内分班、AP 数量、科学竞赛 | SHSAT（特殊高中）、ISEE/SSAT（私校） |
| **对写作的要求** | 说明文、实验报告、技术文档 | 议论文、文学评论、研究论文（含引注规范） |
| **对口语的要求** | 项目演示（presentation） | 课堂研讨发言（discussion-based grading） |

### 3.2 同时对标意味着什么

| 能力线 | 来自哪一边 | 具体要求 | 现有方案是否覆盖 |
| :-- | :-- | :-- | :-: |
| 科技非虚构阅读 | 硅谷 | 能读科普长文、图表、实验描述 | 🟡 部分（Kay 系列、Kurzgesagt） |
| 文学分析 | 纽约 | 能分析主题、象征、叙事视角 | 🟡 部分（有讨论题，无分析框架） |
| 论证写作 | 两地 | claim–evidence–reasoning 结构 | 🔴 **完全缺失** |
| 口头表达 | 纽约 | 研讨发言、观点辩护 | 🔴 **完全缺失** |
| 学术词汇 | 两地 | AWL + 希腊拉丁词根 | 🔴 **基本缺失** |

## 四、五维能力标尺（G5→G8）

| 维度 | Grade 5 | Grade 6 | Grade 7 | Grade 8 |
| :-- | :-- | :-- | :-- | :-- |
| **阅读难度** | 740–1010L | 925–1050L | 1000–1120L | 1050–1185L |
| **阅读量** | 60–80 万词/年 | 80–100 万词/年 | 100–130 万词/年 | 130–150 万词/年 |
| **文本类型** | 文学 50% / 信息 50% | 文学 48% / 信息 52% | 文学 46% / 信息 54% | **文学 45% / 信息 55%** |
| **写作** | 5 段式说明文<br>（300–500 词） | 摘要 + 回应<br>书评（500 词） | 议论文<br>（含证据，600–800 词） | 研究论文<br>（含 MLA 引注，1000 词+） |
| **口语** | 3 分钟主题陈述 | 5 分钟 book talk | 研讨发言 + 追问 | 结构化辩论 |
| **词汇** | 学科基础词 | 希腊拉丁词根入门 | Academic Word List | AWL + 学科术语 |

> **阅读量参考依据**：Anderson、Wilson & Fielding（1988）的经典研究显示，阅读量处于全美 90 百分位的学生，年课外阅读量约 180 万词；50 百分位约 28 万词。**两者相差 6 倍以上**——这是词汇量差距最主要的来源。

## 五、差距诊断：现有方案能走到哪

对照 [english-book.md](english-book.md) 的现有书单做实测评估。

### 5.1 蓝思分布 vs 目标带

| 现有书单档位 | 代表书目 | 蓝思 | 对应 CCSS 学段 |
| :-- | :-- | :-: | :-- |
| 入门 | New Kid | GN320L | Grade 2–3 |
| 主力 | Percy Jackson、Holes、Wonder | 660–790L | Grade 4–5 |
| 进阶 | Harry Potter #1–3 | 880–940L | Grade 5–6 |
| 现有天花板 | Kay's Anatomy | 1060L | Grade 6–7 |
| **目标（Grade 8）** | — | **1050–1185L** | — |
| **缺口** | — | **1100–1185L 几乎空白** | — |

**结论**：现有书单能把孩子稳稳送到 **Grade 6–7 水平**，但**够不到 Grade 8 的上限**。缺的不是数量，是 1100L 以上的高难度材料——而这一档几乎全是非虚构。

### 5.2 文本类型比例失衡（最关键的问题）

现有文档第五章写着「奇幻负责拉动兴趣，现实题材负责沉淀思维，建议按 **3 : 1** 搭配」。这个比例是 **75% 文学 / 25% 信息类**。

| | 现有方案 | CCSS Grade 8 目标 | 差距 |
| :-- | :-: | :-: | :-: |
| 文学类 | ≈ 75% | 45% | **超出 30 个百分点** |
| 信息类 | ≈ 25% | 55% | **少 30 个百分点** |

> **为什么这件事影响很大**：美国高中和大学的阅读量里，绝大部分是论文、史料、实验报告、评论文章，而不是小说。SAT 阅读、AP 各科、SHSAT 全都以信息类文本为主。**只读小说的孩子会在 Grade 8–9 遇到一堵墙**——不是词汇不够，是没受过"读论证"的训练。
>
> **但不要矫枉过正**：3 : 1 的设计初衷（用兴趣拉动阅读习惯）在起步阶段是对的。建议按年龄渐进调整，见 6.1。

### 5.3 三个结构性缺口

| # | 缺口 | 现状 | 后果 |
| :-: | :-- | :-- | :-- |
| 1 | **输出为零** | 书单全是"读/听/看"，无写作任务 | 美国强区 Grade 7 已要求带证据的议论文，届时零基础 |
| 2 | **无口头表达训练** | 只有亲子讨论，无结构化输出 | 纽约私校课堂参与度直接计入成绩 |
| 3 | **词汇路径偏低** | Vocabulary.com 用的是 grade-5 词表 | 对标 Grade 8 需要 AWL 和词根体系 |

## 六、补强方案

### 6.1 文本类型比例渐进调整表

不要一次性砍掉小说，按年龄平滑过渡：

| 阶段 | 年龄 | 文学 : 信息 | 做法 |
| :-- | :-: | :-: | :-- |
| 当前（起步） | 10–11 | 70 : 30 | 保持兴趣驱动，每读 3 本小说穿插 1 本非虚构 |
| 过渡 | 11–12 | 60 : 40 | 加入新闻与杂志类短文，每天 1 篇 |
| 对标 | 12–13 | **50 : 50** | 非虚构升级为主线之一，开始读一手史料 |
| 进阶 | 13–14 | **45 : 55** | 达到 CCSS Grade 8 标准 |

### 6.2 非虚构书单补强（按类型）

**A. 叙事性非虚构（Literary Nonfiction）—— 最佳过渡桥梁**

读起来像小说，但内容是真实历史与科学。这是 CCSS 特别强调的类别。

| 书名 | 作者 | 蓝思 | 主题 |
| :-- | :-- | :-: | :-- |
| **Bomb: The Race to Build the Atomic Bomb** | Steve Sheinkin | 920L | 原子弹研发与间谍战，纽伯瑞银奖 |
| **The Boys Who Challenged Hitler** | Steve Sheinkin | 1000L | 丹麦少年抵抗运动 |
| **Chasing Lincoln's Killer** | James Swanson | 1010L | 林肯遇刺后的追捕，节奏极快 |
| **Hidden Figures**（Young Readers 版） | Margot Lee Shetterly | 1000L | NASA 非裔女数学家 |
| **Unbroken**（Young Adult 版） | Laura Hillenbrand | 1010L | 二战战俘生还史 |
| **The Immortal Life of Henrietta Lacks**（Young Readers 版） | Rebecca Skloot | 1000L | 医学伦理，衔接 Kay 系列 |
| **I Am Malala**（Young Readers 版） | Malala Yousafzai | 1000L | 教育权与勇气 |

### 6.3 写作训练阶梯

| 阶段 | 目标文体 | 训练重点 | 篇幅 | 频率 |
| :-- | :-- | :-- | :-: | :-- |
| **第 1 阶** | 段落写作 | 主题句 + 支撑句 + 结论句 | 100–150 词 | 每周 2 篇 |
| **第 2 阶** | 5 段式说明文 | 引言—三个论点—结论 | 300–500 词 | 每周 1 篇 |
| **第 3 阶** | 书评 / 摘要回应 | 概括 + 个人观点 + 文本证据 | 500 词 | 每本书 1 篇 |
| **第 4 阶** | 议论文 | **CER 框架**：Claim（主张）→ Evidence（证据）→ Reasoning（推理） | 600–800 词 | 每两周 1 篇 |
| **第 5 阶** | 研究论文 | 多来源检索 + MLA 引注 + 参考文献 | 1000 词+ | 每学期 1–2 篇 |

### 6.4 口语与思辨训练

| 形式 | 做法 | 频率 | 对标什么 |
| :-- | :-- | :-- | :-- |
| **Book Talk** | 读完一本书，做 3–5 分钟英文口头介绍（不看稿） | 每本书 | 硅谷 presentation 文化 |
| **家庭苏格拉底研讨** | 就一个开放性问题围坐讨论，规则：必须引用文本、必须回应上一个人 | 每周 1 次 | 纽约 Harkness 课堂 |
| **结构化辩论** | 正反方各 3 分钟陈述 + 2 分钟质询 | 每月 1–2 次 | SHSAT/私校面试的思维基础 |
| **影子跟读** | 跟读 TED-Ed 或 CNN 10，模仿语调节奏 | 每天 10 分钟 | 发音与流利度 |

> 现有文档已推荐 **Smash Boom Best** 播客（趣味辩论），是家庭辩论最好的入门模板——听完直接模仿其攻防结构即可。

### 6.5 学术词汇升级路径

| 阶段 | 内容 | 工具 |
| :-- | :-- | :-- |
| 现在 | Vocabulary.com grade-5 词表 | 已在用 |
| 下一步 | **升级到 grade-7 / grade-8 词表** | vocabulary.com |
| 核心 | **希腊拉丁词根**（约 100 个词根可覆盖上万学术词） | Membean、Wordly Wise 3000 |
| 目标 | **Academic Word List（AWL）** 570 个词族 | 覆盖学术文本约 10% 的词汇 |
| 学科 | 各科专业术语（科学、历史、数学） | 随教材积累 |

> **词根的杠杆效应**：Percy Jackson 里的希腊神话专有名词（Chronos → chronology、Titan → titanic、Pan → panic）本身就是词根教学的天然素材。**把神话阅读和词根学习绑在一起，是这个书单独有的优势**，别浪费。

## 八、关键考试地图

| 考试 | 全称 / 用途 | 适用年级 | 频率 | 是否必须 |
| :-- | :-- | :-: | :-- | :-- |
| **MAP Growth** | 学业进步测评，定位与追踪 | K–12 | 每年 2–3 次 | ⭐ 强烈建议（唯一能纵向比较的工具） |

## 九、执行建议与常见误区

### 9.1 六个常见误区

| 误区 | 为什么错 | 正确做法 |
| :-- | :-- | :-- |
| **只读小说** | 美国中学后 55% 的阅读是信息类；SAT/AP 几乎全是非虚构 | 按 6.1 的比例表逐步调整 |
| **只输入不输出** | 读 100 本不写 1 篇，写作能力为零 | 每本书至少一次口头或书面输出 |
| **盲目追高蓝思** | 超出当前水平 150L 以上会挫败 | 坚持 i+1，只高 50–100L |
| **把蓝思当唯一标准** | 蓝思只测句长和词频，测不出思想深度 | 蓝思用于筛选，质量靠奖项和书评判断 |
| **忽视词根** | 死记单词效率极低 | 100 个希腊拉丁词根撬动上万词 |
| **一次性买齐所有书** | 书堆积产生心理压力 | 分批采购，读完 3 本再买下一批 |

### 9.2 每周时间配置建议（对标版，约 8–10 小时/周）

| 模块 | 每周时长 | 内容 |
| :-- | :-: | :-- |
| 文学精读 | 2.5 小时 | 主线小说，不查词只标记 |
| 非虚构阅读 | 2 小时 | 叙事性非虚构 + 每日新闻 |
| 写作输出 | 1.5 小时 | 按 6.3 阶梯，每周 1–2 篇 |
| 口语表达 | 1 小时 | Book talk / 家庭研讨 / 辩论 |
| 词汇 | 1 小时 | 词根 + AWL + Vocabulary.com |
| 视听输入 | 1.5 小时 | 播客 + YouTube + CNN 10 |

### 9.3 季度检查清单

| 检查项 | 达标标准 |
| :-- | :-- |
| ☐ MAP RIT 或蓝思值 | 每季度提升 3–5 RIT 或 30–50L |
| ☐ 累计阅读词数 | 达到该年龄段年目标的 1/4 |
| ☐ 文学 : 信息比例 | 符合当前阶段目标配比 |
| ☐ 完成写作篇数 | 至少 6 篇成稿 |
| ☐ 口头输出次数 | 至少 6 次 book talk 或研讨 |
| ☐ 孩子的主观感受 | **仍然愿意读——这一项否决其他所有项** |

---

> **📌 一句话总结**：对标硅谷和纽约，差的不是书的数量，而是三件事——**信息类文本的比例、写作输出的训练、学术词汇的体系**。现有书单在"点燃兴趣"这一环做得很好，下一步是把它从"阅读书单"升级为"能力体系"。
>
> **但请记住最后那条检查项**：所有对标目标的前提，是孩子还愿意读。一个 900L 但主动读的孩子，三年后会超过一个 1100L 但被逼着读的孩子。

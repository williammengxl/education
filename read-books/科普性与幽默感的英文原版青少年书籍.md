#### 为什么是"科普幽默"的天花板

```
Bill Bryson 的写作公式：
= 海量查证的准确知识 
+ 讲故事的天赋（每个知识点都有人物故事） 
+ 英式自嘲幽默（把自己写成"什么都不懂的好奇普通人"） 
+ 对科学家怪癖的精彩描写

例：他描写牛顿——
"牛顿是个被仇恨驱动的人。他一生中大部分精力
 不是花在发现宇宙规律上，而是花在毁灭得罪他的人的事业上。"
```
